# JAYARAMSRK

Static, multi-page GitHub Pages site for “The business of what comes next.”

## Run locally

From the repository root, run `python3 -m http.server 8000` and open `http://localhost:8000`.

## Deploy

Push the `main` branch to `JayaramSRK/JayaramSRK.github.io`. GitHub Pages serves the root of `main`; no build step is required.

## Edit the data

Portfolio cards are driven by `data/projects.json`. Replace the clearly labelled illustrative values with verified case data, then update the project URLs and supporting evidence. The site uses only static HTML, CSS and JavaScript so it can be edited directly in GitHub.

## Supply before final publication

- Real photo or logo
- Verified credentials and badge URLs
- Verified case-study data and source permissions
- LinkedIn, email and calendar URLs
- Executive profile PDF and vCard details
